# know-thy-build-demo — Notes API

작은 팀이 HTTP만으로 메모를 남기고 다시 찾을 수 있게 하는 최소 노트 API. dark factory 파이프라인의 dogfood 대상이다.

## Problem

메모는 사람마다 다른 곳(로컬 파일, 채팅 DM, 위키 초안)에 흩어져 있고, 며칠 뒤 "그거 어디에 적었더라"로 끝난다. 위키는 구조를 요구해서 30초짜리 메모를 받아주지 못하고, 채팅은 받아주지만 되찾을 수 없다. 남길 곳이 없는 게 아니라 **되찾을 수 있게 남길 곳**이 없다.

## Principles

### 입력은 30초 안에 끝난다 (NON-NEGOTIABLE)
노트 생성에 필수 필드는 `title`과 `body` 둘뿐이다. 태그·폴더·권한 같은 필드를 필수로 추가하지 않는다.

### 되찾기가 기능의 절반이다
목록과 검색은 생성과 같은 우선순위다. 검색 없는 릴리스는 릴리스가 아니다.

### 조용히 버리지 않는다
검증 실패는 4xx와 이유로 답한다. 잘린 본문·무시된 필드를 조용히 저장하지 않는다.
